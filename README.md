# Dice-roller-game
Dice roller game with roll animation. Click button to roll dice 1-6 with shake effect. Tracks total rolls. Built with HTML, CSS &amp; Vanilla JavaScript.
Day 19/100 of #100DaysOfCode. 3D Dice roller game with roll animation. Generates random numbers 1-6 with CSS 3D transforms. Tracks total rolls and last 5 results. Built to practice CSS 3D, keyframe animations, and Math.random(). Tech: HTML5, CSS3, Vanilla JavaScript, CSS 3D Transforms, Keyframe Animation.
